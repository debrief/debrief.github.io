    Class: StacExtensionProperties¶

    Extension properties added to STAC item.properties under the debrief: namespace. All properties are optional — existing items without extension properties remain valid. These properties enable filtering, searching, and colour-coding in the Discovery UI.

    Slots¶

    Name Cardinality and Range Description Inheritance
    platforms *
    PlatformRecord    		 Fully-resolved per-platform metadata array direct
    tags *
    String    		 Plot-level tags — free-text labels applied to the entire plot by the analyst direct
    feature_tags *
    String    		 Union of all feature-level tags from the plot's GeoJSON features direct
    overrides *
    String    		 Flat list of field names on item direct
    provenance_log *
    PropertiesProvenanceEntry    		 Per-commit provenance entries written by the Properties Panel direct
